# dsh-media-desk

给 DeepSeek Harness（DSH）用的自媒体工作台：把「作品台账 → 数据复盘 → 发布包」串成一条线。

只服务一件事：**自己的抖音个人号**（当前 2 个）。不是通用发布器，不是多平台矩阵工具。

## 边界（先划清，免得越做越大）

| 做 | 不做 |
|---|---|
| 作品台账：一作品一行，一次报数一行 | 上传自动化（上传这事人点按钮） |
| 复盘：播放中位数、赞/评、评论赞比、互动率、T+ 龄期、按内容型分组 | 抓平台私有接口、逆向签名 |
| 发布包：标题 + 简介 + 5 个 tag + 封面尺寸校验，导出成可直接粘贴的文本 | 把平台创作中心嵌进面板 |
| 每周提醒导出数据（后台只留 30 天、最后 100 条） | 多平台分发（超出抖音 2 号再说） |

## 为什么不做上传

四个平台的官方发布接口是「文档里有、个人拿不到权限」：

- **抖音**：开放平台有「上传视频」与「创建视频」，但代投稿 scope `video.create.bind` 属实验室能力，官方公告自 2024-07-20 起收回；
- **小红书**：scope 页至今只有 `basic_info` 开放，`write_notes` 仍标「规划中」；
- **B站**：确有视频稿件提交接口，但入驻要求企业资质（营业执照 + 申请公函），个人开发者申请未开通；
- **视频号**：未见对外的发布接口。

抓私有接口（`a_bogus` / `x-s` / wbi 签名）随平台版本换，维护成本远高于「省下几次点击」，而且封的是自己的账号。

**所以：插件把发布包送到手边，上传这一步留给人。**

## 数据模型（初稿）

`data/posts.jsonl` —— 一条作品一行：

| 字段 | 含义 |
|---|---|
| `id` | `p0001` 顺序号 |
| `date` | 稿件日期 |
| `account` | 账号简称 |
| `kind` | 内容型（口播 / 图文tag / 混剪 …） |
| `title` | 标题 |
| `url` | 作品链接（归档用，不参与统计） |
| `published_at` | 实际发布时刻，用于算 T+ 龄期 |
| `note` | 备注 |

`data/metrics.jsonl` —— 一次报数一行：

| 字段 | 含义 |
|---|---|
| `id` | 对应 `posts.id` |
| `captured_at` | 报数时刻（真实时间，用于取最新快照） |
| `play` / `like` / `comment` / `share` / `collect` | 播放、赞、评、转、藏 |
| `fans` | 当时粉丝数（归档用） |
| `source` | 手动抄 / 导出表 |

口径固定三条：

1. 同一作品多次报数**取最新那条**（按 `captured_at` 真时间，不按写入顺序）；
2. 用**中位数**不用均值（一条爆款会把均值拉飞）；
3. T+ 龄期是**现算**的（`captured_at - published_at`），不是记下来的；混龄期的数不可比，要么按 T+ 对齐，要么加时间窗过滤。
